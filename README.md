# Удобный календарь

Устанавливаемый веб-календарь (PWA): сегодня, месяц и «сколько осталось» до событий,
выходных, праздников и зарплаты. Без подключения к календарю устройства — всё хранится
локально в браузере.

**Сайт:** https://dimmik.github.io/good-calendar/

## Что умеет

- **Сегодня:** дата, часы, статус дня (рабочий / выходной / праздник), номер недели,
  прогресс дня, рабочего дня, недели, месяца и года.
- **Месяц:** праздники и выходные, события и выплаты в клетках, число рабочих дней.
  Любой день можно сделать выходным или рабочим вручную. Страна выбирается в настройках:
  - **Сербия** (по умолчанию) — по Закону о государственных и других праздниках:
    1–2 января, 7 января, 15–16 февраля, 1–2 мая, 11 ноября и православная Пасха
    с Великой пятницы по понедельник (дата Пасхи вычисляется). Если день государственного
    праздника выпадает на воскресенье, нерабочим становится следующий рабочий день
    (субботы не переносятся). Савиндан, Видовдан, 9 мая и дни памяти отмечаются, но рабочие.
  - **Россия** — производственный календарь (2025–2026 по постановлениям, дальше — по
    правилам ТК; переносы на новые годы добавляются в `RU_DECREES` в `js/rules.js`).
  - **Только сб и вс.**
- **Сколько осталось:** до зарплаты (по умолчанию 5-е число; если оно выходное или
  праздник — ближайший рабочий день раньше), до выходных, до конца рабочего дня, до
  ближайшего праздника, до Нового года и до своих событий (разовых, ежегодных,
  ежемесячных, еженедельных). Меньше суток — живой таймер.
- **Перенос между устройствами:** ⛓ в шапке → ссылка и QR-код со всеми событиями и
  настройками. Открыли на другом устройстве → «Объединить» или «Заменить».
  Удаления тоже переносятся при объединении.
- **Синхронизация (без своего сервера):** события и настройки шифруются в браузере
  (AES-256-GCM, WebCrypto) и лежат одним файлом в GitHub-репозитории (`dimmik/goodcalc-data`,
  `calendar.enc`); браузер пишет туда через GitHub API токеном, у которого доступ только к этому
  репозиторию. Ключ есть только у устройств. Первое устройство: Настройки → Синхронизация →
  «Первое устройство», вставить токен. Остальные: «Подключить другое устройство» → открыть
  ссылку или QR на новом устройстве. Синхронизация при открытии, при возвращении в приложение,
  через пару секунд после изменения и раз в 5 минут; одновременная запись разруливается
  через sha файла, слияние — по времени изменения с учётом удалений.
- **Установка:** работает офлайн (service worker). Манифест подключается и из JS — на случай,
  если блокировщик (AdGuard и т. п.) вырезает `<link rel="manifest">` из HTML; если
  заблокирован и сам файл, манифест собирается в data-URL.

Горячие клавиши на компьютере: ← / → — месяцы, T — сегодня, N — новое событие.

## Устройство

Статический сайт без сборки: `index.html`, `css/app.css`, ES-модули в `js/`
(`dates.js` — даты, `rules.js` — календарь, зарплата, повторы, отсчёты, `store.js` — хранение
и ссылки, `app.js` — интерфейс, `boot.js` — манифест/SW/установка), `sw.js`, `pwa.json`.
QR-коды — [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) (MIT),
лежит в `js/vendor/`.

Локально: `python3 -m http.server` в корне, затем
- `http://localhost:8000/` — приложение;
- `tests/test.html` — тесты логики (результат на странице);
- `tests/seed.html` — заполнить демо-данными (перезаписывает ваши локальные данные!);
- `tests/ui.html` — открыть диалоги для скриншотов;
- `tests/sync-live.html#repo=…&t=…` и `tests/sync-ui.html#repo=…&t=…` — живые проверки
  синхронизации через GitHub (два виртуальных устройства и интерфейс настроек); работают
  с временным файлом в `_selftest/` и удаляют его.
